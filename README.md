# 📚 格格讀書行動營・跨書平行內化系統

支援「**今日跨書工作台**（一天讀 2+ 本書、每本推進一章）」與「**單書完整脈絡**」雙向自動同步的閱讀內化筆記系統。所有筆記會自動儲存在瀏覽器的 `localStorage` 中。

## 🚀 如何使用與部署到 GitHub Pages（免安裝任何環境）

本專案的 [`index.html`](./index.html) 已經整合為**免編譯單一網頁版**，無須安裝 Node.js 或設定複雜的編譯流程：

### 方法一：放到 GitHub Pages 變成專屬線上網站（推薦，手機電腦都能開）
1. 登入你的 [GitHub](https://github.com/) 帳號，點擊右上角 **`+`** ➔ **`New repository`**。
2. 輸入儲存庫名稱（例如 `reading-notes`），勾選 **`Public`**，點擊 **`Create repository`**。
3. 在新建立的頁面中，點擊 **`uploading an existing file`**（上傳現有檔案）。
4. 將本資料夾中的 **`index.html`** 拖曳進去，點擊下方的 **`Commit changes`**。
5. 點擊儲存庫上方的 **`Settings`**（設定）➔ 左側選單點擊 **`Pages`**。
6. 在 **Build and deployment** 下的 **Branch** 選擇 **`main`**（或 `master`），點擊 **`Save`**。
7. 等待約 1 分鐘後重新整理頁面，上方就會出現你的專屬網址（例如 `https://你的帳號.github.io/reading-notes/`），點開即可永久使用！

### 方法二：在自己電腦上直接打開使用
- 直接用滑鼠雙擊點開資料夾內的 **`index.html`**，就會在瀏覽器（Chrome / Edge / Safari）中直接執行並自動儲存你的讀書筆記。
